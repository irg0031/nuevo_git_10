## Tabla de comandos basicos de git y su explicacion

| Comando  | Explicación |
| ------------- |:-------------:|
| git init  | Inicializa un nuevo repositorio local de Git en el directorio actual  |
| git clone  | Crea una copia local completa de un repositorio remoto existente    |
| git add .  |   Añade archivos a la zona de preparación (staging area) para el próximo commit   |
| git commit     |  Registra una instantánea de los cambios preparados en el historial del repositorio |
| git push     |  Envía los commits locales al repositorio remoto  |
| git checkout  |  Cambia entre ramas o restaura archivos del árbol de trabajo (método clásico) |
| git switch     |  Cambia de rama de una forma más intuitiva y clara que `checkout` |
| git status     |   Muestra el estado actual del directorio de trabajo y de la zona de preparación  |
| git fetch  |  Descarga los últimos cambios, ramas y un historial actualizado desde un repositorio remoto |
| git pull    |  Descarga y fusiona los cambios del repositorio remoto en la rama actual |
| git  rebase  |  Vuelve a aplicar commits sobre otra base de rama para mantener un historial lineal |
| git merge  | Fusiona la historia de una rama específica en la rama actual  |
| git  log   |  Muestra el historial de commits para la rama activa |
